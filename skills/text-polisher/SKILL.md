# Text Polisher

Use this skill when the user asks to polish, rewrite, tighten, simplify, professionalize, or improve a short piece of text such as a message, paragraph, note, announcement, or short email draft.

## Workflow

1. Preserve the user's original meaning, factual claims, names, dates, numbers, links, and explicit tone request.
2. Improve clarity by removing filler, fixing grammar, choosing direct wording, and making sentence flow smoother.
3. Keep the output close to the user's requested length. If no length is requested, stay roughly similar to the original.
4. Return only the polished text unless the user asks for explanation, alternatives, or a critique.
5. If the source text is ambiguous in a way that could change meaning, briefly ask for clarification instead of inventing details.

## Style Variants

For ordinary polishing, handle the rewrite directly.

Read [references/style-guide.md](references/style-guide.md) when the user asks for a specific style such as formal, friendly, concise, assertive, warm, or diplomatic, or when they ask for multiple tone options.
